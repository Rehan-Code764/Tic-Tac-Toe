# Tic-Tac-Toe
🎮 A responsive Tic-Tac-Toe web game built with HTML, CSS, and JavaScript, featuring a neon UI, sound effects, winning animations, scoreboard, and mobile responsiveness
# 🎮 Tic-Tac-Toe Game

## ✨ Features

- 🎯 Two-player Tic-Tac-Toe gameplay
- 💜 Neon X and 💙 O design
- 🏆 Automatic winner detection
- 📊 X Wins, O Wins & Draws scoreboard
- ✨ Animated winning line
- 🔊 Move sound effects
- 🎵 Background music
- 🎉 Winner popup with GIF animation
- 🔄 Reset Game button
- 📱 Fully responsive for mobile and desktop
- 🌌 Modern neon/glowing UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- CSS Flexbox
- HTML5 Audio
